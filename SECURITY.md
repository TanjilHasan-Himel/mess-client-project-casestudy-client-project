# Publication security policy

This repository contains sanitized documentation, not the private SmartMess application source.

Please do not open a public issue containing credentials, private endpoints, resident information, financial records, client identifiers, unredacted screenshots, or detailed vulnerability reproduction steps. Use GitHub's private vulnerability-reporting channel if it is available for this repository, or contact the repository owner through their GitHub profile.

Public documents follow these rules:

- no application source code or environment configuration;
- no secrets, tokens, internal endpoints, or complete private schema;
- no real resident or financial data;
- no screenshot without data and metadata review;
- no unsupported security, performance, adoption, or business-outcome claim;
- human approval before publication.
